## Central dispatcher

The dispatcher in `server.javelin.dispatch` provides type-id-indexed encode/decode routing for all 40 captured wire-types plus 0x5d1 (state-10 trigger). It's the canonical entry point for any code that wants a single call instead of importing each per-type module.

- **`decode_replay_message`** (`function`) — Decode a captured replay message into its codec dataclass.
- **`encode_replay_message`** (`function`) — Encode a codec dataclass back into wire bytes.
- **`supported_type_ids`** (`function`) — The set of type-ids the dispatcher knows how to decode.
- **`encodable_type_ids`** (`function`) — The set of type-ids the dispatcher knows how to encode.
- **`DECODERS`** (`value`) — `dict[int, decoder]` — 40 entries; the type-id → decoder routing table.
- **`ENCODERS`** (`value`) — `dict[int, encoder]` — 41 entries; the type-id → encoder routing table.
