# Static RE Dashboard

A self-contained mobile-friendly site visualizing the New World private-server RE work. Single-page app, no build step beyond regenerating `data.json`.

## Local preview

```
.venv/bin/python3 tools/build_site.py    # regenerate data.json
cd site && python3 -m http.server 8000   # browse http://localhost:8000
```

## Hosting (free options)

### GitHub Pages — wired up via Actions

Live at: **https://nw-private-server.github.io/first-light/**

GitHub Pages can only serve from `/` or `/docs` directly, so deploys
go through `.github/workflows/pages.yml` instead. The workflow runs
on every push to `claude/vacation-2026-05-06` that touches `site/`,
`tools/build_site.py`, the analysis inputs, or the codec library —
regenerates `site/data.json` on the runner, uploads `site/` as the
Pages artifact, and deploys.

Trigger a deploy manually with:
```
gh workflow run pages.yml --ref claude/vacation-2026-05-06
```

To switch which branch deploys, edit the `branches:` list in the
workflow.

### Cloudflare Pages

- Connect the GitHub repo
- Build command: `python3 tools/build_site.py`
- Build output: `site`
- Root: `/`

### Netlify

Same as Cloudflare. Build command + output identical.

### Plain static (no build)

Since `data.json` is committed alongside the HTML, any host that serves
static files from `site/` works — no Node/Python build needed at deploy time.

## Regenerating

The data is regenerated by `tools/build_site.py` from these inputs:
- `info/typeregistry.json` (3487 type entries)
- `info/nw-login-safe-20260502-153840/messages-redacted.txt` (replay)
- `analysis/typename_mapping.csv` (auth names)
- `analysis/decomp_*.txt` (Ghidra decompiles)
- `server/javelin/*.py` (codec library)

Each loop wake should:
```
.venv/bin/python3 tools/build_site.py
git add site/data.json site/decomp/
```

Including the rebuild in the commit keeps the live site in sync with the
underlying analysis.

## What's on the site

- **Overview**: top-level stats (tests, codecs, captured types, etc.)
- **Wire Types**: all 40 captured wire-types with names + UUIDs + codec module + confidence levels
- **Codecs**: codec module inventory with descriptions
- **Decompiles**: Ghidra decompile previews (linked to per-function `.txt` files)
- **Findings**: curated major findings from the worklog
